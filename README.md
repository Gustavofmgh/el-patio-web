# El Patio · Propuestas de web

Tres diseños para la web de El Patio con el mismo contenido. Abre `index.html` para elegir.

- `v1/` Cuaderno · `v2/` Cartel · `v3/` Preguntas
- **Contenido:** todo sale de `datos.js` (ponentes, charlas, fragmentos, próximo patio). Es el único archivo que hay que tocar.
- **Tipografía:** Times New Roman MT Pro Condensed (Monotype, de pago). Coloca `TimesNRMTPro-Cond` y `TimesNRMTPro-BoldCond` (.woff2/.otf/.ttf) en `fonts/`. Sin ellos se usa Noto Serif Display estrecha.
- **Ver en local:** doble clic en `Abrir web.command`, o `python3 -m http.server` y abre http://localhost:8000.
